## 🎯 Objetivo

O objetivo deste material é ajudar você a compreender como os agentes de IA funcionam, quais componentes fazem parte de sua arquitetura e como esses sistemas podem ser projetados para executar tarefas orientadas a objetivos.

O foco está nos fundamentos e nas decisões arquiteturais, independentemente de uma linguagem de programação ou framework específico.

**Este é um material conceitual, sem código**, voltado à compreensão dos princípios que fundamentam os sistemas agênticos.

## 💡 Conceito fundamental

Um agente de IA não é simplesmente um modelo de linguagem com um prompt. É um sistema que combina um objetivo com contexto, capacidade de decisão, ferramentas e mecanismos de controle para executar uma tarefa.

Sua arquitetura deve ser adequada ao problema: nem toda aplicação precisa de um agente, e nem todo agente precisa de múltiplos agentes para funcionar.

## Como estudar

Se você está começando, recomendamos seguir a ordem dos conteúdos.

1. Comece pelos fundamentos para entender o que caracteriza um agente de IA.
2. Explore a arquitetura para conhecer os componentes que tornam sua execução possível.
3. Estude os padrões de raciocínio para compreender como os agentes planejam, agem e revisam suas decisões.
4. Conheça as abordagens de construção e os sistemas multiagentes.
5. Finalize com segurança, avaliação e governança.

Você também pode consultar diretamente qualquer tema de interesse.

O material é ideal para pessoas que estudam ou trabalham com Inteligência Artificial, Ciência de Dados, Engenharia de Software e desenvolvimento de aplicações baseadas em LLMs.
